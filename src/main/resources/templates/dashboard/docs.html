Dokumentasi API & Panduan Integrasi

Jelajahi dokumentasi lengkap tentang API OCR kami, termasuk endpoint, parameter, contoh respons, dan panduan implementasi untuk integrasi yang optimal.

  1. 🔑

    API Key Anda

    Semua permintaan ke API harus disertai dengan API key yang dikirimkan dalam header.

    X-API-KEY:
  2. 📝

    Endpoint Ekstraksi Teks

    Endpoint:

    POST /api/ocr/do-ocr

    Deskripsi: Mengunggah dokumen untuk diproses oleh sistem OCR.

    Header:

    Content-Type: multipart/form-data
X-API-KEY:

    Body (Form-Data):

    Nama Jenis Deskripsi
    image file File gambar dokumen (JPG atau PNG)
    imageUrl string Url gambar dokumen
    requiredKeys string array List kata kunci yang ingin diambil dari hasil ekstraksi gambar (Opsional)

    * Catatan: untuk image dan imageUrl bisa dipilih antara salah satu.

    Response :

    • 200 OK 

    {
	"data": {
		"requestId": 4,
		"status": "WAITING",
		"duration": null,
		"originalExtractedText": null,
		"extractedTexts": null
	},
	"success": true,
	"errorMessage": null,
	"statusCode": null
}
  3. ⏳

    Mengecek status ekstraksi

    Endpoint:

    GET /api/ocr/check-status/{requestId}

    Deskripsi: Memeriksa apakah proses ekstraksi telah selesai.

    Header:

    X-API-KEY:

    Response :

    • 200 OK 

    {
	"data": {
		"requestId": 2,
		"status": "DONE",
		"duration": 7.0,
		"originalExtractedText": null,
		"extractedTexts": null
	},
	"success": true,
	"errorMessage": null,
	"statusCode": null
}

    • 400 Bad Request 

    {
	"data": null,
	"success": false,
	"errorMessage": "Request with id : 2 not found!",
	"statusCode": null
}
    Status Request Deskripsi
    WAITING Status ini menunjukkan bahwa permintaan OCR telah diterima tetapi belum diproses. Biasanya terjadi ketika permintaan sedang dalam antrean sebelum dieksekusi oleh sistem.
    PROCESSING Status ini menandakan bahwa sistem sedang memproses dokumen OCR. Proses ini melibatkan ekstraksi teks dari gambar atau dokumen yang diunggah pengguna.
    DONE Status ini berarti proses OCR telah selesai dan hasilnya sudah tersedia. Teks yang diekstrak bisa langsung digunakan atau disimpan untuk keperluan selanjutnya.
    FAILURE Status ini menunjukkan bahwa proses OCR gagal. Kegagalan bisa terjadi karena beberapa alasan, seperti format dokumen tidak didukung, gambar buram, atau kesalahan sistem.
