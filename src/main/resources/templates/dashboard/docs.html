Dokumentasi API & Panduan Integrasi

Semua yang kamu butuh untuk integrasi: otentikasi, endpoint, contoh request/response, dan penanganan error. Copy-paste ready.

API Key Anda

Sertakan di setiap request via header X-API-KEY

Required
•••• 
X-API-KEY: your_api_key
Hanya 1 key aktif per akun.
POST

Ekstraksi Teks

POST /api/ocr/do-ocr

multipart/form-data

Header

Content-Type: multipart/form-data
X-API-KEY: key

Body (pilih salah satu)

FieldTypeDesc
imagefileJPG/PNG, max 5MB
imageUrlstringURL publik gambar
requiredKeysstring[]Filter key hasil (opsional)
200 OKasync — return requestId
{
  "data": {
    "requestId": "3f2a4df5-bd72-9250-fef2cab06603",
    "status": "WAITING",
    "duration": null,
    "extractedTexts": null
  },
  "success": true
}
💡 Gunakan requiredKeys untuk hanya ambil field yang dibutuhkan (mis. nik, nama) — mengurangi noise.
Lihat contoh cURL ▾ 
curl -X POST https://api.nestara.id/api/ocr/do-ocr \
  -H "X-API-KEY: YOUR_KEY" \
  -F image=@ktp.jpg \
  -F requiredKeys=nik \
  -F requiredKeys=nama
GET

Cek Status

GET /api/ocr/check-status/{requestId}

polling 2s 
X-API-KEY: key
StatusArti
WAITINGAntre, belum diproses
PROCESSINGSedang ekstraksi
DONESelesai, siap ambil hasil
FAILUREGagal (format/buram/error)
200 OK
{
  "data": {
    "requestId": "3f2a4df5...",
    "status": "DONE",
    "duration": 7.0
  },
  "success": true
}
