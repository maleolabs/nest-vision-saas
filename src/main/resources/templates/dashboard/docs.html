Dokumentasi API & Panduan Integrasi

Jelajahi dokumentasi lengkap tentang API OCR kami, termasuk endpoint, parameter, contoh respons, dan panduan implementasi untuk integrasi yang optimal.

  1. 🔑

    API Key Anda

    Semua permintaan ke API harus disertai dengan API key yang dikirimkan dalam header.

    Authorization: Bearer {API_KEY}
  2. 📝

    Endpoint Ekstraksi Teks

    Endpoint:

    GET /api/extract/status/{request_id}

    Deskripsi: Mengunggah dokumen untuk diproses oleh sistem OCR.

    Header:

    Content-Type: multipart/form-data
Authorization: Bearer {API_KEY}

    Body (Form-Data):

    Parameter Jenis Deskripsi
    file file File gambar dokumen (JPG, PNG, PDF)
    metadata string Data tambahan opsional dalam format JSON

    Response (200 OK):

    {
  "request_id": "1234567890abcdef",
  "status": "processing"
}
  3. ⏳

    Mengecek status ekstraksi

    Endpoint:

    GET /api/extract/status/{request_id}

    Deskripsi: Memeriksa apakah proses ekstraksi telah selesai.

    Header:

    Authorization: Bearer {API_KEY}

    Response (200 OK):

    {
  "request_id": "1234567890abcdef",
  "status": "completed"
}

    Jika masih diproses:

    {
  "request_id": "1234567890abcdef",
  "status": "processing"
}
  4. ✅

    Mengambil hasil ekstraksi

    Endpoint:

    GET /api/extract/result/{request_id}

    Deskripsi: Mengambil hasil ekstraksi teks setelah proses selesai.

    Header:

    Authorization: Bearer {API_KEY}

    Response (200 OK):

    "request_id": "1234567890abcdef",
  "status": "completed",
  "extracted_text": "Ini adalah hasil ekstraksi teks dari dokumen."
}

    Jika belum selesai:

    {
  "error": "Processing not completed"
}
  5. ⚠️

    Kesalahan umum

    Kode Deskripsi
    400 Permintaan tidak valid
    401 API key tidak valid atau tidak diberikan
    404 Data tidak ditemukan
    500 Kesalahan server
