Preprocessing Otomatis

Tesseract + OpenCV. Denoise, deskew, koreksi perspektif, dan threshold dijalankan otomatis sebelum ekstraksi — termasuk untuk foto yang blur, miring, atau kurang terang.

⚡

Async & Andal

Ekstraksi berjalan sebagai async job dengan polling status — request tidak blocking. Fallback multi-engine membantu meningkatkan tingkat keberhasilan ekstraksi.

</>

Mudah Integrasi

Satu endpoint multipart, X-API-KEY header, response JSON konsisten. Contoh cURL & JavaScript siap pakai di dokumentasi.

Integrasi dalam 3 langkah

Dari registrasi sampai response JSON pertama — tanpa konfigurasi rumit.

01
Dapatkan API Key

Daftar → verifikasi email → buat API key dari dashboard.

02
POST /api/ocr/do-ocr

Kirim image / imageUrl + optional requiredKeys.

03
Poll & Get Result

GET /check-status → GET /get-result. Selesai.
