Kebijakan Privasi

Terakhir diperbarui: 21 Agustus 2026

Data yang kami proses

  • Data akun: nama, email, dan tipe akun saat registrasi. Email digunakan untuk verifikasi akun.
  • Gambar yang diunggah: file gambar yang kamu kirim untuk diekstraksi disimpan di server (direktori uploads/ocr-request).
  • Hasil ekstraksi: teks asli dan field terstruktur hasil OCR, terkait dengan request ID kamu.
  • Log request: timestamp, endpoint, status, dan durasi setiap panggilan API untuk keperluan kuota harian dan audit.

Cara kami menggunakan data

  • Menjalankan fitur OCR yang kamu minta.
  • Menerapkan batas kuota harian per akun.
  • Menampilkan riwayat penggunaan di dashboard kamu.

Kami tidak menjual atau membagikan data kamu kepada pihak ketiga untuk tujuan iklan atau pemasaran.

Retensi & keamanan

  • API key disimpan dalam bentuk terenkripsi dan memiliki masa berlaku.
  • Gambar dan hasil ekstraksi tersimpan di server selama akun aktif. Hubungi operator layanan untuk penghapusan permanen.
  • Akses ke server dibatasi untuk operasional layanan.

Tanggung jawab kamu atas data

Jika kamu mengunggah dokumen yang berisi data pribadi orang lain (misalnya KTP), pastikan kamu memiliki dasar hukum untuk memprosesnya dan sesuai dengan peraturan perlindungan data yang berlaku (termasuk UU PDP No. 27/2022).

Perubahan kebijakan

Kebijakan ini dapat diperbarui seiring perkembangan layanan. Perubahan material akan diumumkan melalui halaman ini.
